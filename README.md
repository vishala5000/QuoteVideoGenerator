# Quote Video Generator

An Android app that generates videos from quotes with custom styling and background music.

## Features

- 📹 Generate H.264 (AVC) videos at 1080x1920px
- 🎨 Custom font support (font.ttf)
- 🎵 Background music support (bg.mp3)
- 📝 Text wrapping with center alignment
- 🎯 Multiple quotes support (up to 10)
- 📦 ZIP file output for easy sharing
- 🤖 CI/CD with GitHub Actions

## Requirements

- Android 7.0+ (API 24+)
- 100MB storage space
- Internet permission (for future updates)
